# AI-Compliance-Agent-Project

## **What it does:**
- It reviews AI prompts and outputs & flags risk before potential damage happens
Checks prompt before it gets sent to the analysis agent for safety (whether the prompt includes sensitive info like names or credit card details or anything of that nature), appropriateness, assumptions and data accuracy, and risk of hallucination in output
- It Provides suggestions for how to better structure & improve your prompt

## **IT DOES NOT:**
- Provide legal advice -> output should tell the user that explicitly and ask them to consult professional services
- No strong language -> this agent is only meant to be an assistant not a service provider
